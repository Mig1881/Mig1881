## Proyectos destacados

### [Cinemas](https://github.com/Mig1881/Cinemas)  
ApiCinema es una API REST robusta para la gestión de venta de entradas de multicines. Este proyecto ha sido desarrollado como una actividad de aprendizaje avanzada para el Acceso a Datos, utilizando tecnologías modernas y siguiendo estándares de seguridad industrial.

**Tecnologías:** Java 21, Spring Boot 3.x, MariaDB 11.3.2, Docker, JWT, JUnit y Newman.

**Qué demuestra:** Toma de requisitos, análisis de negocio, modelado de datos y diseño adaptado a las necesidades del cliente, dockerización de entornos, implementación de seguridad mediante tokens JWT y diseño de APIs REST.

### [Astro-launch](https://github.com/Mig1881/Astro-launch)  
AstroLaunchX es una aplicación web interactiva desarrollada con React y TypeScript para el seguimiento de misiones espaciales de SpaceX. El proyecto integra datos reales mediante APIs, ofreciendo una experiencia de usuario fluida, moderna y adaptativa.
**Tecnologías:** React, TypeScript, SpaceX API v4.  

**Qué demuestra:** Desarrollo frontend moderno, consumo de APIs externas, manejo del estado y diseño de interfaces.

### [TheGreatRubiosBrothers](https://github.com/Mig1881/TheGreatRubiosBrothers)  
Es un videojuego de plataformas en 2D que rinde homenaje a la era dorada de los 8 bits (C64). Vive una aventura llena de peligros, enemigos mecánicos y puentes que se desmoronan, todo bajo una atmósfera retro cuidadosamente recreada.

**Tecnologías:** Java 21, libGDX, Tiled.  
**Qué demuestra:** Programación orientada a objetos, gestión de bucles de renderizado y estructuración de proyectos multimedia.

### [DiscordServer](https://github.com/Mig1881/DiscordServer)  
Un backend robusto y escalable diseñado para emular las funcionalidades principales de Discord. Desarrollado con NestJS, este proyecto incluye autenticación segura, gestión de servidores y canales, control de roles (RBAC), y comunicación en tiempo real.

**Tecnologías:** NesJS, TypeORM(PostgreSQL, SQLite), JWT, Bycrypt, @nestjs/websockets, Socket.io, Jest).  

**Qué demuestra:** Modelado de datos, uso de NesJS e integración de WebSockets (Socket.io) para emitir mensajes en tiempo real.

### [SanValero_Burger_Android](https://github.com/Mig1881/SanValero_Burger_Android)  
Esta es una aplicación Android nativa desarrollada para gestionar y votar en el certamen de hamburguesas más importante de la ciudad. La app permite a los usuarios explorar Food Trucks, descubrir nuevas hamburguesas, gestionar las inscripciones del concurso y visualizar los detalles de cada participante.

**Tecnologías:** Java (Android SDK), arquitectura MVP, Rerofit 2 + Gson para comunicacion con API, Glide, Material Design Components

**Qué demuestra:** Desarrollo de aplicacion movil con Android Studio.
